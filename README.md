# 🚀 DevPortfolio & Blog — GitHub Pages Project Showcase

Современный сайт-портфолио и блог разработчика на **React + TypeScript + Tailwind CSS + shadcn/ui**, полностью готовый к мгновенному развёртыванию на **GitHub Pages**.

Сайт автоматически подключается к **GitHub API**, загружает ваши публичные репозитории, даёт возможность интерактивно листать их, переключаться между ними (включая управление стрелками на клавиатуре) и детально изучать каждый проект:
- 📖 **README.md** с подсветкой синтаксиса, форматированием GitHub Flavored Markdown и авто-резолвом относительных ссылок на картинки.
- 🖼️ **Галерея скриншотов и медиа** (автоматический поиск в папках `screenshots/`, `assets/`, `images/` и извлечение картинок из `README.md` с полноэкранным зумом).
- 📂 **Просмотрщик документации (`/docs`)** (интерактивное дерево файлов репозитория с мгновенным чтением `.md` файлов без перехода на GitHub).
- 📊 **Инсайты и статистика** (процентное распределение языков программирования, звёзды, форки, быстрая команда для `git clone`).
- ✍️ **Инженерный блог** со статьями, тегами и временем чтения.
- 🌓 **Тёмная и светлая тема** с сохранением выбора.

## ⚡ Быстрый старт локально

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере: `http://localhost:5173`

## 🌐 Развёртывание на GitHub Pages

Сайт уже настроен для работы в любом подкаталоге GitHub Pages (`base: './'`). Есть **два простых способа** опубликовать его:

### Способ 1: Автоматически через GitHub Actions (Рекомендуемый)

В проекте уже создан готовый рабочий процесс [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

1. Создайте репозиторий на GitHub (например, `my-portfolio` или `username.github.io`).
2. Инициализируйте git и отправьте код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: modern github portfolio"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИКНЕЙМ/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings** → **Pages**:
   - В разделе **Build and deployment** выберите **Source: GitHub Actions**.
4. Всё! При каждом `git push` сайт автоматически собирается и публикуется.

### Способ 2: В одну команду через `gh-pages`

Если вы предпочитаете ручную публикацию ветки `gh-pages`:
```bash
npm run deploy
```
*(В настройках репозитория **Settings** → **Pages** выберите **Deploy from a branch** → ветка `gh-pages`)*.

## ⚙️ Настройка профиля и проектов

### Изменение профиля в коде (`src/config.ts`)
Откройте файл [`src/config.ts`](src/config.ts) и укажите ваши данные:

```typescript
export const siteConfig: SiteConfig = {
  // Ваш никнейм на GitHub
  githubUsername: 'ВАШ_НИКНЕЙМ',
  name: 'Ваше Имя',
  tagline: 'Full-stack Engineer & Open Source Creator',
  bio: 'Описание вашего опыта и интересов...',
  socials: {
    github: 'https://github.com/ВАШ_НИКНЕЙМ',
    telegram: 'https://t.me/ваш_юзернейм',
    // ...
  },
  // Репозитории, которые хотите закрепить первыми
  featuredRepos: ['my-best-project', 'awesome-app'],
  // Статьи для блога
  blogPosts: [ ... ],
};
```

### Смена аккаунта прямо на сайте
В правом верхнем углу сайта есть кнопка с шестерёнкой **GitHub Settings**:
- Можно ввести любой GitHub никнейм и сайт сразу отобразит его проекты.
- Можно указать **Personal Access Token (PAT)**, если вы хотите снять стандартное ограничение GitHub API (60 запросов/час для неавторизованных IP расширяется до 5 000 запросов/час). Токен сохраняется исключительно в вашем браузере (`localStorage`).
- Можно очистить кэш запросов.

## ⌨️ Управление и горячие клавиши

- **В карусели проектов**:
  - Кнопки `←` и `→` (или клавиши `K` и `J`) быстро переключают текущий проект.
  - Полоса быстрых табов позволяет прыгнуть к любому проекту в 1 клик.
- **В детальном окне проекта**:
  - Нажатие `←` / `→` на клавиатуре листает проекты прямо внутри открытого модального окна без его закрытия!
  - `Esc` — закрыть окно или полноэкранный просмотр скриншота.
