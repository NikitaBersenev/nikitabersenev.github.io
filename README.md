# nikitabersenev.github.io

Минималистичный список публичных GitHub-проектов.

- только чёрный фон и белый текст;
- список репозиториев на главной;
- отдельный внутренний route для каждого проекта;
- README.md загружается напрямую с GitHub;
- отображаются stars, forks, issues, дата обновления и языки;
- без профиля, блога, настроек, фильтров и декоративного UI.

## Локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Деплой выполняется через GitHub Actions в GitHub Pages.
